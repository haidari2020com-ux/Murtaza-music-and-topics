پروژه اندرویدی Murtaza Music and Topics

این پروژه، فایل HTML آزمایشی شما را داخل یک برنامه اندرویدی WebView قرار می‌دهد.
برای ساخت APK:
1) پروژه را در Android Studio باز کنید.
2) اجازه دهید Gradle و Android SDK موردنیاز دریافت شوند.
3) از منوی Build گزینه Build APK(s) را انتخاب کنید.

شناسه برنامه: app.murtaza.musicandtopics
حداقل نسخه اندروید: Android 6.0 (API 23)
نسخه فعلی: 1.0.0

توجه: این فایل ZIP سورس پروژه اندروید است، نه APK نصب‌شده. این محیط ابزار Android SDK/Gradle لازم برای کامپایل APK را ندارد.
محتوای HTML اولیه در app/src/main/assets/index.html قرار دارد.

ساخت APK بدون نصب Android Studio روی گوشی (با GitHub Actions):
1) فایل ZIP را در یک مخزن جدید GitHub بارگذاری و Extract کنید (فایل‌ها باید در ریشه مخزن باشند).
2) به زبانه Actions بروید و اجرای workflow با نام Build Android APK را انتخاب کنید.
3) پس از پایان موفق، در بخش Artifacts فایل Murtaza-Music-and-Topics-APK را دریافت کنید.
این روش به حساب GitHub و اتصال اینترنت نیاز دارد؛ فایل APK را پس از ساخت از همان بخش دانلود می‌کنید.
